# Tu instante en π / Your Moment in π

Candidata para revisión privada. Abre una copia local con `python3 -m http.server 8765 --bind 127.0.0.1` y visita http://127.0.0.1:8765/.

La app calcula el primer millón de decimales de π con el algoritmo de Chudnovsky y comprueba su SHA-256 antes de buscar. La ausencia de una secuencia se limita al tramo examinado. La normalidad de π sigue sin demostrarse.

The app computes and checks the first million decimal digits of π locally before searching. A miss applies only to that range.
